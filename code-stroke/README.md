# Code Stroke NIHSS

A 3D, VR and mixed-reality simulator for practising the NIH Stroke Scale, the vessel call and acute treatment decisions (thrombolysis, thrombectomy or medical management) across 12 stroke cases.

**Play:** open the GitHub Pages link for this repository in any browser. On a Meta Quest 3, open it in the Quest Browser and press **Enter VR** or **Mixed reality**.

- Desktop and phone: walk the ward, examine each patient, score the 15 NIHSS items and get a debrief.
- Quest 3 VR: point with the controllers or pinch with your hands; the left stick walks and the right stick turns.
- Quest 3 mixed reality: the ward's beds, patients and monitors appear in your own room through colour passthrough.

Teaching simulation only. Follow local protocols.
